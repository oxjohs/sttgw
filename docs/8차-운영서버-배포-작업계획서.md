# 8차 운영서버 배포 작업계획서

## 1. 목적

본 문서는 `sttgw` 프로젝트를 운영 대상 서버 `211.192.89.96` 에 배포하고, 초보 개발자도 그대로 따라 하면서 기동과 기본 검증까지 수행할 수 있도록 상세 절차를 정의한다.

이번 문서의 목표는 아래 3가지를 모두 충족하는 것이다.

1. 서버에 애플리케이션을 안전하게 배포한다.
2. 서비스가 `prod` 프로파일로 정상 기동하는지 확인한다.
3. 실제 통화 기반 STT 검증을 시작할 수 있는 상태까지 만든다.

## 10. 패킷 캡처 권한 부여

Pcap4J가 `eth3` 를 읽으려면 Java 프로세스에 네트워크 capability가 필요할 수 있다.

```bash
sudo setcap cap_net_raw,cap_net_admin=eip $(readlink -f $(which java))
```

확인:

```bash
getcap $(readlink -f $(which java))
```

## 12. 백그라운드 실행 스크립트

초보 개발자는 수동 기동으로 먼저 검증한 뒤, 그 다음 스크립트 방식으로 전환하는 것이 안전하다.

### 12.1 start.sh 생성

파일 경로:

- `/APP/sttgw/bin/start.sh`

내용:

```bash
#!/bin/bash
APP_HOME="/APP/sttgw"
JAR_FILE="${APP_HOME}/sttgw-0.0.1-SNAPSHOT.jar"
PID_FILE="${APP_HOME}/sttgw.pid"
LOG_FILE="/APP_LOGS/sttgw/startup.log"

export GOOGLE_APPLICATION_CREDENTIALS="${APP_HOME}/credentials/google-stt-key.json"

nohup java -jar "${JAR_FILE}" \
  --spring.profiles.active=prod \
  --spring.config.additional-location=file:${APP_HOME}/application.yaml \
  > "${LOG_FILE}" 2>&1 &

echo $! > "${PID_FILE}"
echo "started pid=$(cat ${PID_FILE})"
```

### 12.2 stop.sh 생성

파일 경로:

- `/APP/sttgw/bin/stop.sh`

내용:

```bash
#!/bin/bash
PID_FILE="/APP/sttgw/sttgw.pid"

if [ ! -f "${PID_FILE}" ]; then
  echo "pid file not found"
  exit 1
fi

PID=$(cat "${PID_FILE}")
kill "${PID}"
rm -f "${PID_FILE}"
echo "stopped ${PID}"
```

### 12.3 권한 부여

```bash
chmod +x /APP/sttgw/bin/start.sh
chmod +x /APP/sttgw/bin/stop.sh
```
